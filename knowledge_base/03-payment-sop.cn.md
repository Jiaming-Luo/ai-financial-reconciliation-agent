# 付款对账操作流程

Document ID: KB-03
Version: 1.0
Language: cn
Scope: 模拟医院检测费用对账原型
Status: SIMULATION

> 模拟业务规范，仅用于项目演示。本文不代表实际企业制度、监管要求或行业法律规定。

## 1. 归集与校验收款

按医院编号和指定结算期归集收款。实际付款日期可能处于另一日历月。同组中多笔具有不同有效参考号的付款可以是正常分次收款。

Review guidance: 核对结算归属，并逐笔追溯付款参考号。

## 2. 重复付款与参考号冲突

在全量付款文件中检查参考号。有效副本的医院、付款日期、结算期、金额和币种都一致时，标记 DUPLICATE_PAYMENT，仅按字典序最小的付款编号计入一次，保留复核标志。副本内容冲突或有无效副本时，参考号未解决，挂起受影响结算组。

Review guidance: 核对原始收款凭证，保留全部证据，并交由复核人员确认参考号冲突。

## 3. 付款缺失与无对应业务付款

可计算但没有收款的业务组为 MISSING_PAYMENT。没有业务行的有效收款组为 UNMATCHED_PAYMENT。仅缺少收款不能认定逾期。保留收款或业务证据，不自行跨期分摊。

Review guidance: 与财务复核人员核查结算月份及源数据导入范围。
