# 数据质量及校验规范

Document ID: KB-05
Version: 1.0
Language: cn
Scope: 模拟医院检测费用对账原型
Status: SIMULATION

> 模拟业务规范，仅用于项目演示。本文不代表实际企业制度、监管要求或行业法律规定。

## 1. 文件与标识校验

校验三份源 CSV 的结构、必填值和原始记录编号。合同、业务及付款编号用于标识原始行。重复交易参考号按付款规则处理。保留无效原始行并报告问题。

Review guidance: 对照数据字典核查错误并保留原始记录编号。

## 2. 日期、数量及金额校验

校验日历日期和结算月份。合同价格、收款金额及整数数量必须为正，申报金额允许为零。金额使用人民币并精确到分。匹配合同决定允许的计费单位。

Review guidance: 申请更正前，核对源字段格式与合同计费单位。

## 3. 临时运行与测试数据隔离

无法可靠归组的问题可能使运行处于临时状态。报告问题，Agent 暂不展示总体金额。预期异常案例仅用于测试，不参与财务计算或知识问答。

Review guidance: 先处理未归组问题，再使用总体金额。本原型仅使用模拟输入。
